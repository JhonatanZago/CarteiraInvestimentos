# Especificação: frontend premium

## Requisitos
- A navegação principal deve ser superior e responsiva, sem menu lateral roxo.
- O dashboard deve selecionar carteira real, exibir patrimônio, indicadores, composição e posições sem dados fictícios.
- Carteiras, posições, ativos e corretoras devem ter formulários claros, busca, CRUD e estados vazios orientativos.
- Posições devem usar selects nomeados de ação/corretora, nunca IDs digitados.
- Todos os fluxos devem oferecer loading, sucesso, erro compreensível, foco visível e suporte a teclado.
- O layout deve funcionar em desktop, tablet e celular e compilar sem erros Angular.
